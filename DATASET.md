# Dataset Notes

## File

`smartcart_customers.csv` is the source dataset used by `smartcart.ipynb` for customer segmentation and clustering.

## Contents

The dataset contains a customer identifier, demographic fields, household information, spending measures, purchase-channel activity, recent engagement, and campaign-response fields.

## Intended Use

Use this dataset only for the SmartCart clustering analysis and related educational or portfolio work. Preserve the original file when reproducing the notebook so the analysis remains consistent.

## Privacy and Sharing

Although the dataset does not include direct contact fields such as names or email addresses, it includes demographic and financial-behavior attributes. Confirm that public sharing and reuse are permitted before redistributing it, and avoid attempts to identify individual customers.
