# SmartCart Clustering System

A customer-segmentation project that applies clustering techniques to identify meaningful customer groups and support data-informed engagement strategies.

## Overview

This repository contains the complete SmartCart clustering project: the analysis notebook, source dataset, and supporting project documentation. The workflow is designed to explore customer behavior, prepare relevant features, and interpret the resulting segments.

## Repository Contents

| File | Description |
| --- | --- |
| `smartcart.ipynb` | End-to-end data analysis and customer clustering workflow. |
| `smartcart_customers.csv` | Customer dataset used by the notebook. |
| `SmartCart Clustering System.pdf` | Project report and supporting documentation. |

## Getting Started

1. Clone this repository.
2. Install the Python packages imported by `smartcart.ipynb`.
3. Launch Jupyter Notebook or JupyterLab.
4. Open `smartcart.ipynb` and run the cells in order.

## Project Workflow

- Review and prepare the customer data.
- Explore the variables used for segmentation.
- Build and evaluate customer clusters.
- Interpret the groups to support business decisions.

## Data Use

The dataset is provided for this project only. Please handle customer information responsibly and avoid using it for purposes outside the scope of this analysis.
